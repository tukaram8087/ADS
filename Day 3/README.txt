Java ADS Assignments 1 to 6
============================

Each assignment is organized in its own Java package folder.

Included:
- assignment1: Singly linked list (delete, deleteAll, search)
- assignment2: Doubly linked list (search, delete, deleteAll)
- assignment4: Recursive quotient (positive and negative numbers)
- assignment5: Recursive remainder (positive and negative numbers)
- assignment6: Optimized recursive multiplication (positive and negative numbers)

Assignment 3 was not included because its question/details were not provided in the conversation.

How to run:
1. Import/extract this folder into your IDE as a Java project.
2. Keep the package declarations and folder structure unchanged.
3. Run the Main.java file in the desired assignment package.
